## 4. What Is a Git Repository?

A Git repository is a project directory whose changes are tracked using Git.

Git maintains a history of changes through commits, allowing developers to track their progress and manage different versions of their work.

GitHub is an online platform used to host Git repositories, share projects, and collaborate with other developers.

## 5. Why Is the Repository Organised by Mission?
