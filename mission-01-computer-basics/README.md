# Mission 1 — Know Your Computer

## Objective

To understand how a computer receives input, processes data, produces output, and stores information. This mission also explores hardware, software, and computer-based systems used in everyday life.

## Task 1.1 — Trace One Activity Using IPOS

### Activity: Typing and Saving a Document

I used Visual Studio Code on my MacBook to type and save a Markdown document.

| Stage | What happens in my example? | Hardware / Component |
|---|---|---|
| Input | I type text using the keyboard. | Keyboard |
| Processing | The CPU processes the input while RAM temporarily holds the document data. | CPU and RAM |
| Output | The typed text appears in the VS Code editor. | Display |
| Storage | I press Command + S to save the document. | SSD |

### Explanation

When I type using my keyboard, the computer receives input. The CPU processes the information, and RAM temporarily holds the document data.

The screen displays the text as I type. When I press Command + S, the document is saved to the SSD, allowing me to access it again later.

### Observation

I observed that text appeared in the editor as I typed. After saving and reopening the document, the saved content remained available.

## Task 1.2 — Identify Hardware and Software

Hardware refers to physical components of a computer. Software consists of programs and instructions that help the computer perform different operations.

| Item / Software Name | Hardware or Software? | Software Type | Purpose |
|---|---|---|---|
| Keyboard | Hardware | Not applicable | Enter text and commands |
| Trackpad | Hardware | Not applicable | Control the pointer |
| Display | Hardware | Not applicable | Show visual output |
| SSD | Hardware | Not applicable | Store files and applications |
| macOS | Software | Operating system | Manage hardware and system resources |
| Visual Studio Code | Software | Application | Write and edit code or documents |
| Brave Browser | Software | Application | Browse websites |
| Disk Utility | Software | Utility | Manage and inspect storage devices |

### Explanation

Operating system software manages the computer's hardware and resources.

Application software allows users to perform tasks, such as writing code or browsing websites.

Utility software helps maintain, configure, or manage the computer.

### Observation

I identified physical components of my MacBook and classified examples of software according to their functions.

## Task 1.3 — Computer Systems Around You

Many everyday devices contain computer systems that receive input, process information, and generate output.

| System | Main Purpose | One Input | One Output |
|---|---|---|---|
| ATM | Perform banking transactions | PIN entered through keypad | Cash dispensed |
| Smart TV | Display entertainment content | Remote-control command | Video on screen |
| Ticket Vending Machine | Sell tickets | Destination selected using touchscreen | Printed ticket |

### Explanation

An ATM processes banking requests and can dispense cash.

A smart TV processes commands from its remote control and displays entertainment content.

A ticket vending machine processes ticket selections and produces the requested ticket.

These examples demonstrate how computer systems are used beyond laptops and smartphones.
